## ความสามารถ

### สมาชิก

- ลงทะเบียนด้วยชื่อจริง นามสกุล ชื่อเล่น และ PIN ความยาว 4–6 หลัก
- ถ่ายภาพใบหน้าและให้ความยินยอมก่อนจัดเก็บข้อมูลใบหน้า
- รับรหัสสมาชิกโดยอัตโนมัติ
- เข้าสู่ระบบด้วยชื่อ PIN และการตรวจจับใบหน้าในเบราว์เซอร์
- ดูแดชบอร์ดและประวัติการเข้าใช้งาน
- เปลี่ยนภาพและข้อมูลใบหน้าที่ใช้ยืนยันตัวตน
- ออกจากระบบเพื่อบันทึกเวลาออก

### เจ้าหน้าที่

ผู้ใช้ที่เข้าสู่ระบบด้วยบัญชี Django Staff สามารถ:

- เปิดคิวรายการที่รอบันทึกยอดขายที่ /counter/

- ดูรายงานสรุปยอดประจำวันที่ /reports/daily/
- จัดการข้อมูลผ่าน Django Admin ที่ /admin/

### การจัดเก็บข้อมูล

- SQLite ใช้เก็บข้อมูลสมาชิก ประวัติการเข้าใช้งาน และยอดขาย
- PIN ถูกแฮชก่อนจัดเก็บ

## ตั้งค่าไฟล์ .env

คัดลอก .env.example เป็น .env แล้วกำหนดค่าที่ต้องการ:

| ตัวแปร | ความหมาย |
| --- | --- |
| DJANGO_SECRET_KEY | กุญแจลับของ Django ให้สร้างค่าใหม่และเก็บเป็นความลับ |
| DJANGO_DEBUG | โหมดพัฒนา ตั้งเป็น 1 สำหรับทดลอง และปิดเป็น 0 เมื่อใช้งานจริง |
| FACE_MATCH_THRESHOLD | เกณฑ์ระยะห่างสำหรับจับคู่ใบหน้า ค่าเริ่มต้นคือ 0.5 |
| GOOGLE_SHEET_ID | รหัส Google Spreadsheet (ไม่บังคับ) |
| GOOGLE_SHEET_WORKSHEET | ชื่อ worksheet ที่ต้องการใช้ หากเว้นว่างจะใช้ชีตแรก |
| GOOGLE_SERVICE_ACCOUNT_FILE | ตำแหน่งไฟล์ข้อมูลรับรองของ service account (ไม่บังคับ) |
| GOOGLE_SERVICE_ACCOUNT_JSON | ข้อมูลรับรองรูปแบบ JSON ใช้แทนการระบุไฟล์ได้ |
| DJANGO_ALLOWED_HOSTS | รายชื่อโดเมนที่อนุญาต คั่นแต่ละรายการด้วยเครื่องหมายจุลภาค |

ห้ามส่งไฟล์ .env หรือข้อมูลรับรองขึ้น Git และห้ามใส่ข้อมูลลับไว้ใน README หรือซอร์สโค้ด

ค่าตั้งต้นเหมาะสำหรับการพัฒนาในเครื่องเท่านั้น ก่อนเปิดให้ใช้งานผ่านเครือข่ายสาธารณะ ให้ตั้ง DJANGO_SECRET_KEY ใหม่ ปิด DJANGO_DEBUG กำหนด DJANGO_ALLOWED_HOSTS ใช้ HTTPS และวางแผนจัดเก็บกับสำรองข้อมูลอย่างปลอดภัย

## แชร์เว็บชั่วคราวผ่าน Cloudflare Tunnel

ให้ติดตั้ง cloudflared ก่อน จากนั้นเปิด PowerShell ในโฟลเดอร์เดียวกับ manage.py แล้วรัน:

~~~powershell
powershell -ExecutionPolicy Bypass -File .\start-public.ps1
~~~

สคริปต์จะเปิดเว็บในเครื่องและแสดงลิงก์ trycloudflare.com ในหน้าต่าง PowerShell ส่งลิงก์นั้นให้ผู้ใช้ได้ ระหว่างแชร์ต้องเปิดเครื่องและหน้าต่าง PowerShell ค้างไว้ การปิดโปรแกรมจะหยุดเว็บ และลิงก์ใหม่จะเปลี่ยนเมื่อเริ่มใช้งานครั้งถัดไป

ลิงก์นี้เปิดเว็บสู่สาธารณะ ให้ใช้ข้อมูลทดสอบเท่านั้น ไม่ควรใช้กับข้อมูลสมาชิกหรือข้อมูลใบหน้าจริง

## เข้า Django Admin ผ่านลิงก์ Cloudflare

ขณะเปิดเว็บด้วย start-public.ps1 ให้นำลิงก์ trycloudflare.com ที่แสดงใน PowerShell มาเติม /admin/ ต่อท้าย แล้วเข้าสู่ระบบด้วยบัญชี Django Superuser

หากยังไม่มีบัญชี Superuser ให้เปิด PowerShell อีกหน้าต่างในโฟลเดอร์เดียวกับ manage.py แล้วรัน:

~~~powershell
.\venv\Scripts\python.exe manage.py createsuperuser
~~~

กำหนดชื่อผู้ใช้และรหัสผ่านตามขั้นตอน จากนั้นใช้บัญชีนี้เข้าสู่ Django Admin อย่าใช้บัญชีสมาชิกทั่วไป และอย่าแชร์รหัสผ่านผู้ดูแลระบบ
